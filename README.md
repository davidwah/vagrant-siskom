# Vagrant Sistem Komputer Lab

A reproducible virtual machine environment designed to support hands-on learning in computer systems and operating system administration.

## Overview

This project provides an automated way to provision a virtual machine using Vagrant, helping students focus on learning system administration instead of manually preparing virtual environments.

## Learning Objectives

By completing this lab, students should be able to:

- Understand virtualization concepts.
- Provision virtual machines using Vagrant.
- Access Linux environments through SSH.
- Understand basic VM lifecycle management.

## Technologies

- Vagrant
- VirtualBox
- Linux
- SSH

## Prerequisites

- Vagrant installed
- VirtualBox installed
- Git installed
- Minimum 8 GB RAM recommended for the host machine

## Getting Started

Clone the repository:

```bash
git clone https://github.com/davidwah/vagrant-siskom.git
cd vagrant-siskom
```

Start the virtual machine:

```bash
vagrant up
```

Access the VM:

```bash
vagrant ssh
```

Stop the VM:

```bash
vagrant halt
```

## Practical Exercises

1. Inspect the VM configuration.
2. Start and stop the virtual machine.
3. Access the VM through SSH.
4. Explore Linux system information.
5. Practice basic Linux administration commands.

## Expected Outcomes

Students should be able to provision, access, and manage a virtual machine using Vagrant.
